# HackerRank In-Browser IDE

The HackerRank IDE lets you write, compile, and test code directly in your browser.

## Features

- Syntax highlighting for all supported languages.
- Auto-indent and bracket matching.
- "Run Code" button: run against sample test cases immediately.
- "Submit Code" button: run against all test cases (both visible and hidden).
- Custom test input: paste your own input to test edge cases.
- Multiple language selection from a dropdown.

## Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| Run code | Ctrl+Enter / Cmd+Enter |
| Save | Ctrl+S / Cmd+S |
| Comment/uncomment | Ctrl+/ / Cmd+/ |
| Increase font size | Ctrl+= |
| Decrease font size | Ctrl+- |

## Common IDE Issues

### Code Not Saving
If you see unsaved changes, click the "Save" button manually. The IDE auto-saves every 30 seconds when online. If you lose internet connection, save locally and paste again when reconnected.

### IDE Not Loading
1. Clear browser cache and cookies.
2. Disable browser extensions (especially ad-blockers).
3. Try a different browser — Chrome or Firefox are best supported.
4. Ensure JavaScript is enabled.

### Wrong Language Selected
Change the language from the dropdown above the editor. Your existing code will not be automatically converted.

## Using Your Own Editor

For some challenge types, you can write code locally and paste it into the IDE. However:
- This may flag your session if the company has "copy-paste detection" enabled.
- Always check the assessment instructions before doing this.
