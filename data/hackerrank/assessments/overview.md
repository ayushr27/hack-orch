# HackerRank Assessments Overview

HackerRank Assessments allow companies to evaluate candidates through coding challenges, MCQs, and project-based tests.

## Types of Assessments

- **Coding Challenges**: Algorithm and data structure problems in 40+ languages.
- **Multiple Choice Questions (MCQ)**: Knowledge-based questions with instant grading.
- **Project-based Tests**: Full-stack or domain-specific take-home assignments.
- **SQL Tests**: Database query evaluation with real database backends.

## Candidate Experience

Candidates receive an invite link via email. The link expires after the deadline set by the recruiter.

### Starting an Assessment
1. Click the invite link from your email.
2. Sign in or create a free HackerRank account.
3. Read the instructions carefully before starting.
4. The timer begins only after you click "Start Test".

### During the Test
- Do not close or refresh the browser tab — this may flag your session.
- Use the in-browser IDE or your preferred editor with code submission.
- Save your progress frequently using the "Save" button.
- Internet access rules depend on the company's settings — some tests allow it, others do not.

## Test Case Results

After submitting a solution, you see:
- **Pass / Fail** for each visible test case.
- **Hidden test cases** are evaluated after submission and may differ from sample cases.
- A partial score is awarded for solutions that pass some but not all cases.

## Timeouts

If your solution exceeds the time limit (usually 2–10 seconds per test case), the test case is marked as "Time Limit Exceeded" (TLE). Common causes:
- Nested loops with O(n^2) or worse complexity on large inputs.
- Infinite loops.
- Excessive memory allocation triggering garbage collection.

## Plagiarism and Academic Integrity

HackerRank uses automated similarity detection across submissions. Matches above a threshold are flagged for recruiter review. Appeals must be directed to the company that administered the test — HackerRank support cannot override plagiarism decisions.

## Submission Deadlines

The deadline is set by the recruiting company, not HackerRank. Contact the recruiter directly to request an extension. HackerRank support cannot grant extensions.
